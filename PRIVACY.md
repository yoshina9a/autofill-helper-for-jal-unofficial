# Privacy Policy

Effective date: 2026-05-24

Autofill Helper for JAL (Unofficial) does not collect, store, sell, share, or transmit personal data.

## Data Collection

This extension does not collect any user data.

It does not collect:

- JMB membership numbers
- passwords
- passkeys
- one-time passwords
- cookies
- browsing history
- analytics
- device identifiers
- form contents

## Network Requests

This extension does not make network requests.

All behavior runs locally in the user's browser on:

`https://jallogin.jal.co.jp/contents/login*`

## Permissions

The extension uses a content script limited to the JAL login page. It does not request access to tabs, cookies, storage, browsing history, web requests, or all websites.

## Purpose

The extension adds standard autofill hints to the JMB membership number field so password managers and browsers can more reliably recognize it as a username-style field.

## Affiliation

This extension is not affiliated with, endorsed by, or sponsored by Japan Airlines or the JAL Group.

## Contact

For privacy-related questions, contact the publisher through the Chrome Web Store listing or the linked GitHub repository.
