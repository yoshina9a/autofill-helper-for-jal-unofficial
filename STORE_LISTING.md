# Chrome Web Store Listing Draft

## Name

Autofill Helper for JAL (Unofficial)

## Short Description

Adds username autofill hints to the JAL login page's JMB number field.

## Detailed Description

Autofill Helper for JAL (Unofficial) is a small browser extension that helps password managers and browser autofill recognize the JMB membership number field on the JAL login page.

The extension only runs on `https://jallogin.jal.co.jp/contents/login*`. It adds standard browser autofill hints such as `autocomplete="username"` to the JMB number field.

This extension does not read, store, or transmit your JMB number, passwords, passkeys, cookies, one-time passwords, or browsing history. It does not click login buttons, submit forms, bypass passkeys, bypass MFA, or modify JAL's authentication flow.

This extension is not affiliated with, endorsed by, or sponsored by Japan Airlines or the JAL Group.

## Permissions Explanation

This extension uses a content script limited to the JAL login page so it can add browser autofill hints to the JMB membership number input field.

Requested site access:

`https://jallogin.jal.co.jp/contents/login*`

No other extension permissions are requested.
